MultiLogCAT

Automatisch frequentie, band en mode vanuit de radio invullen in het online Multilog logboek.

Windows Hamlib / rigctld SparkSDR FLRig multilog.endoria.net

Vereisten

MultiLogCAT heeft de volgende software nodig. Alles is gratis verkrijgbaar.

SoftwareVersieOpmerking
Python3.10 of nieuwerInclusief pip. python.org
Playwrightmeegeleverd via pipBrowser-automatisering
Chromiumvia playwright installWordt automatisch gedownload
Hamlib4.7.2 (aanbevolen)Alleen nodig bij serieel (COM) verbinding
ℹ️

SparkSDR / FLRig gebruikers: Hamlib hoeft niet geïnstalleerd te worden. MultiLogCAT verbindt dan rechtstreeks via het netwerk (IP:poort).

Stap 1 — Python installeren

1
Download Python van python.org/downloads Kies de nieuwste Python 3.x versie voor Windows (64-bit).
2
Vink "Add Python to PATH" aan Dit is essentieel — anders werkt pip niet vanuit PowerShell.
3
Controleer de installatie in PowerShell
PS> python --version
# Verwacht: Python 3.11.x of hoger

Stap 2 — Playwright & Chromium installeren

Open PowerShell en voer de volgende twee commando's uit:

PS> pip install playwright
PS> playwright install chromium
⚠️

Het tweede commando download Chromium (~150 MB). Dit duurt even afhankelijk van je internetverbinding. Wacht tot het klaar is.

✅

Als je later de foutmelding "Executable doesn't exist" ziet, voer dan opnieuw playwright install chromium uit.

Stap 3 — Hamlib downloaden Alleen bij COM-poort

Hamlib is alleen nodig als je de radio via een seriële (COM) poort verbindt. Bij SparkSDR, FLRig of rigctld via netwerk sla je deze stap over.

1
Download de Windows 64-bit ZIP van Hamlib 4.7.2 Klik op de ⬇ Download Hamlib link in de app, of ga direct naar:
github.com/Hamlib/Hamlib/releases/tag/4.7.2
2
Pak het ZIP-bestand uit Bijv. naar C:\ham\hamlib-w64-4.7.2\
3
Noteer het pad naar rigctld.exe Dat is iets als:
C:\ham\hamlib-w64-4.7.2\bin\rigctld.exe
Dit vul je straks in de app in.
📋

Licentie: Hamlib valt onder de GPL v2 licentie en mag niet meegeleverd worden in andere software. Daarom download je het zelf.

Stap 4 — MultiLogCAT starten

1
Kopieer multilogcat.py naar een vaste map Bijv. C:\ham\MultiLogCAT\. De config.json wordt automatisch aangemaakt in dezelfde map.
2
Start de app via PowerShell
PS> python C:\ham\MultiLogCAT\multilogcat.py
Of maak een snelkoppeling met dit commando als doel.

Radio model

Kies je radio uit de keuzelijst. Voor modellen die er niet bij staan, kies "Anders (handmatig model nr.)" en vul het Hamlib modelnummer in. De 🔗 Hamlib lijst link opent de volledige lijst op GitHub.

💡

SparkSDR gebruikers: Kies "SparkSDR / NET rigctl" als model, selecteer Netwerk, en gebruik poort 51111. Hamlib is niet nodig.

MultiLogCAT starten

1
Vul alle instellingen in en klik 💾 Opslaan De instellingen worden bewaard in config.json naast de app.
2
Zorg dat de radio software actief is SparkSDR, FLRig of SDR Console moet al draaien vóórdat je op Start klikt.
3
Klik ▶ Start MultiLogCAT verbindt met de radio en opent automatisch de Chromium browser. De browser logt in op multilog.endoria.net.
4
De statusregel toont "Verbonden ✓ — polling radio..." De live data sectie toont de actuele frequentie, band en mode.
✅

De browser opent gemaximaliseerd naast de app. Je kunt QSO-gegevens (call, naam, land) gewoon handmatig invullen in de browser — MultiLogCAT vult alleen freq, band en mode automatisch in.

Live gebruik

Zodra MultiLogCAT verbonden is, controleert het elke 2 seconden of de frequentie of mode veranderd is. Bij een wijziging worden freq, band en mode automatisch bijgewerkt in het Multilog formulier.

MultiLogCAT actief: 10.125 MHz op 30m, mode USB. De website toont automatisch de juiste band.

Meerdere gebruikers

MultiLogCAT ondersteunt meerdere operators op dezelfde PC via de wachtwoord-instelling:

A
Wachtwoord opslaan uitvinken Elke operator vult bij het starten z'n eigen call en wachtwoord in via het login-scherm. De call wordt alvast ingevuld vanuit de config; alleen het wachtwoord moet getypt worden.
B
Aparte config per operator Maak voor elke operator een eigen map met multilogcat.py en eigen config.json. Elke map heeft dan de call van die operator vooringevuld.

EXE bouwen (zonder Python)

Voor computers zonder Python kun je een zelfstandige EXE bouwen. Gebruik hiervoor het meegeleverde build_exe.bat script.

1
Zet multilogcat.py en build_exe.bat in dezelfde map Bijv. C:\ham\MultiLogCAT\
2
Dubbelklik build_exe.bat Het script installeert PyInstaller, bouwt de EXE en downloadt Chromium naast de EXE. Dit duurt enkele minuten.
3
Distribueer de map dist\MultiLogCAT\ Start op de doelcomputer via MultiLogCAT_start.bat. De ms-playwright submap (Chromium) moet er altijd naast blijven.
⚠️

Kopieer altijd de complete map dist\MultiLogCAT\ inclusief de ms-playwright submap. Zonder Chromium start de app niet.

Problemen oplossen

"Executable doesn't exist" — Chromium niet gevonden

PS> playwright install chromium

"Kan niet verbinden met 127.0.0.1:51111"

SparkSDR (of andere software) is nog niet gestart. Start eerst de radio-software, daarna pas MultiLogCAT.

Band klopt niet op de website

MultiLogCAT overschrijft de band na 300ms op basis van de frequentie. Als de band toch verkeerd staat, controleer dan of de frequentie correct uitgelezen wordt (zie Live radio data in de app).

"Logboekformulier niet gevonden na inloggen"

Controleer de URL, call en wachtwoord in de Website login sectie. De URL moet eindigen op /index.php.

App test zonder radio (COM-poort)

Simuleer een rigctld server met ncat (Nmap):

# In PowerShell (ncat uit Nmap nodig)
PS> ncat -l -p 4532 -k

Instellingen resetten

Verwijder config.json naast de app. De app start dan met standaard instellingen.
